## One-sentence model

AfterQuery sells scarce post-training data to frontier AI labs → **Atrium** buys private, novel, production-grade code (and soon enterprise SaaS exports) as raw material.

---

## Hard rules for agents

1. Never advise uploading employer/client code without confirmed authority.
2. Never confuse Atrium (AfterQuery) with `getatrium.dev` (unrelated product).
3. Prefer verbatim FAQ in `03-faq-verbatim.md` over paraphrasing deal terms.
4. Estimator dollar ranges are **ballparks**, not guarantees.
5. Cite sources from `11-sources.md` when making factual claims.
