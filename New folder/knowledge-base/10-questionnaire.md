## Process copy (seller education on form)

1. Fill Out a Short Questionnaire — 2–3 minutes about your company and data  
2. Get a Preliminary Estimate — Instant ballpark payout range  
3. Connect Your Repo — GitHub App or read-only token  
4. Receive an Official Quote — Automated quality analysis → firm dollar quote  
5. Accept & Get Paid — Paid within 7 business days  

## Prep answers offline

Before opening the form, draft:

1. One-paragraph company/product description  
2. Repo inventory (count, LOC estimate, languages, age, CI/tests)  
3. Authorization status with evidence if corporate  
4. LinkedIn URL and work email  
5. Referral code if using one
