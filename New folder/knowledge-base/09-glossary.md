# 09 — Glossary

| Term | Meaning in this KB |
|------|---------------------|
| **Atrium** | AfterQuery’s marketplace for buying private codebases / enterprise data |
| **AfterQuery** | Parent applied research lab selling post-training data & RL envs to AI labs |
| **Firm quote** | Official dollar offer after analyzing the actual dataset |
| **Preliminary estimate** | Non-binding ballpark from questionnaire/estimator |
| **Authored LOC** | Lines of code counted excluding vendored/generated files |
| **Novelty** | How different the code is from already-public corpora |
| **Temp clone** | Short-lived working copy used only for appraisal |
| **Delivery** | After accept: AfterQuery takes the corpus for their use under deal terms |
| **SFT** | Supervised fine-tuning data (prompt–response, often with CoT) |
| **RLHF** | Reinforcement learning from human feedback / preferences |
| **RL environment** | Sandbox where agents act (APIs, MCP, terminal, browser) and get rewards |
| **MCP** | Model Context Protocol — tool/server interface used in agent training |
| **Post-training** | Model improvement after pretraining (SFT, RL, prefs, evals) |
| **Expert network** | AfterQuery’s ~100k professionals producing traces/rubrics (separate from Atrium) |
| **Frontier lab** | Leading foundation-model company (OpenAI, Anthropic, Google DeepMind, etc.) |
| **Referral code** | Optional code on signup; this workspace uses `NCB4YP` |
