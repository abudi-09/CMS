# 07 — Competitive landscape

## Market category

Expert / professional **post-training data**, RL environments, and domain evals — not generic clickwork labeling.

## AfterQuery’s peers (demand-side competition)

| Player | Angle |
|--------|--------|
| Scale AI | Breadth, RL environments, enterprise procurement familiarity |
| Mercor | Expert network, benchmarks, RL envs, lab penetration |
| Surge AI | Expert domains, RLHF, public research/leaderboards |
| Labelbox / Alignerr | Expert network + RL data + private benchmarks |
| Turing | Talent marketplace base → frontier data packs + RL gyms |

## Indirect pressure

- Frontier labs **insourcing** post-training pipelines  
- Hybrid **synthetic + expert rubric/audit** pipelines compressing cost  
- Eval platforms (Braintrust, LangSmith, Patronus) reducing outsourced validation  

## Atrium’s distinct niche

Most competitors pay **people** to produce traces/labels.  
Atrium pays **organizations** (and builders) for **proprietary corpora** — especially private codebases unavailable on the public web.

That makes Atrium complementary to the expert network, not a replacement: contractors supply judgment; Atrium supplies raw private systems.

## Positioning summary

```
AfterQuery moat claims: research-driven failure analysis + software-first in-house data ops + expert network + (via Atrium) private corporate data supply
Weakness risks (analyst): lab concentration, higher cost structure vs marketplace labor, benchmark commoditization
```
